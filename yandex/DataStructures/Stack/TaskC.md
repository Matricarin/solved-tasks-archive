Дан массив a, состоящий из n чисел. 
Для каждого элемента ai​ нужно сказать, сколько элементов левее него он видит. 
ai​ видит aj​, если i > j и ai​>az​ для всех j≤z<i.
Формат ввода

Первая строка содержит единственное число n(1≤n≤3⋅10^5).

Вторая строка содержит n разделенных пробелом чисел ai​ (1≤ai​≤3⋅10^5).
Формат вывода

Единственная строка вывода должна содержать n разделенных пробелом -- видимость каждого элемента влево.
